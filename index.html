Merswel OS: an organization's operating workspace

Merswel OS is an AI-assisted operating platform from Merswel LLC for keeping client work connected to its organizational context. The current private preview supports clients and contacts, work requests, engagements, delivery plans, work items, and an operating Dashboard in one workspace.

Connected tools can extend the workspace with communications, files, scheduling, and contact lookup. Some capabilities depend on explicitly authorized third-party services. Google Workspace connectivity is being prepared; it is not currently connected or available for general use. Other provider integrations are not represented as live by this page.

When Google Workspace becomes available, an authorized organization user will choose whether to connect it and approve the requested permissions. Provider data will be used only for requested platform functionality, not sold or used for advertising. Preparing an action is distinct from carrying out an action in an external service.

Merswel OS is currently in private preview. Public signup is not available.
